# TypeScript Practice Projects

## About This Repository

This repository contains my TypeScript learning exercises and practical coding examples developed during my Full Stack Development training.

The projects focus on understanding TypeScript fundamentals, static typing, functions, modules, and JavaScript interoperability.

## Technologies Used

- TypeScript
- JavaScript
- Node.js

## Topics Covered

- Type Annotations
- Variables and Data Types
- Functions
- Arrays and Objects
- Interfaces and Type Aliases
- Modules and Imports
- Type Declarations
- JavaScript Compilation
- TypeScript Configuration

## Files Included

| File | Description |
|---|---|
| app.ts | Main TypeScript practice file |
| mathUtils.ts | Mathematical utility functions |
| app.js | Compiled JavaScript output |
| mathUtils.js | Compiled utility functions |
| tsconfig.json | TypeScript compiler configuration |
| package.json | Project dependencies and scripts |

## How to Run

1. Clone this repository.
2. Install dependencies using `npm install`.
3. Run the TypeScript compiler using `npx tsc`.
4. Execute the generated JavaScript using Node.js.
